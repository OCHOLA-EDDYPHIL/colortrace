# Fixture asset provenance

No fixture assets are committed yet. Gate G0 requires a generated or expressly licensed fixture.

For every distributable source image, LUT, config, font, audio element, reference, or generated artifact, record:

- stable asset ID and repository path;
- source URL or generator/version/seed;
- author/copyright holder where applicable;
- exact license and proof date;
- modifications and generation procedure;
- SHA-256 digest;
- whether redistribution and commercial use are permitted;
- reviewer and review date.

Do not add proprietary studio material, ambiguous downloads, real production telemetry, private interview content, or assets that imply affiliation.
