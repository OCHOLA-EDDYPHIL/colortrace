# Contributing to ColorTrace

Start work from a GitHub issue and keep each pull request focused on one purpose. Use a
short-lived branch, preserve accepted issue boundaries, and resolve review conversations before
merging.

Do not commit credentials, private data, proprietary material, internal URLs, or unlicensed
assets. Report security-sensitive defects privately rather than opening a public issue.

By contributing, you agree that your contribution is licensed under Apache License 2.0 and that
you will follow the project Code of Conduct.
