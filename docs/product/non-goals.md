# Hackathon non-goals

These exclusions preserve a credible, complete incident-response loop rather than a broad but shallow platform.

## Product exclusions

- Generic observability, chat-with-logs, or render-log copilot
- A replacement for Grafana, a full operations dashboard, or a second telemetry store
- General digital-asset management, review, collaboration, or production tracking
- Multiple color incident classes before the canonical shadowed-LUT case passes all gates
- A creative or aesthetic correctness oracle
- Automatic selection of an approved reference or comparison policy
- Industry-wide prevalence, market-size, or savings claims without primary evidence
- Enterprise multi-tenancy, organization hierarchy, or a full RBAC suite

## Integration exclusions

- Real renderers, render farms, schedulers, artist workstations, or production remediation
- Production Nuke, Maya, Houdini, Resolve, transcode, or delivery-system collectors
- Publicly exposed or write-enabled Grafana MCP
- Grafana IRM as a mandatory canonical state store; it may become an optional projection
- Any runtime AI provider besides Vertex AI/Gemini
- Any agent framework besides Google ADK

## Technical exclusions

- Hidden ground truth in prompts, MCP responses, API payloads, or UI data available to the investigation
- Hardcoded diagnosis or fixture-specific target lists
- Opaque agent authority over evidence, scope, approval, execution, verification, or closure
- Perceptual claims beyond the declared deterministic comparison policy
- Production-grade scale claims based on the small deterministic fixture

## Deferred work

Additional incident classes, ACES AMF ingestion, scheduler adapters, rollout analysis, collectors, multi-project controls, formal market validation, signed retention/export, collaboration, controlled production remediation, expanded perceptual validation, and self-hosted studio packaging belong in the post-hackathon milestone.
