## Runtime exclusion policy

Release code, containers, infrastructure, environment templates, and runtime dependencies must contain no OpenAI, Anthropic, AWS AI, Microsoft AI, local LLM, or third-party agent-framework integration. Developer tooling that is not shipped must not be represented as runtime and must not leak generated private material.

## Entrant-only confirmations

The repository cannot prove age, residence/export/sanctions eligibility, organizer/partner employment exclusions, family/household conflicts, employer or university IP permission, or authority to accept terms. The entrant must privately confirm these without publishing sensitive data.

## Claims policy

Only claim what repository artifacts demonstrate. Do not claim universal color correctness, industry prevalence, specific savings, production safety, or buyer demand without evidence. State that actions are simulator-only and the incident fixture is synthetic.
